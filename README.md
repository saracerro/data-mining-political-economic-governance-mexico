# data-mining-political-economic-governance-mexico
Proyecto de minería de datos (2000-2024) que analiza la relación entre partidos políticos e inflación estatal en México utilizando INEGI. Incluye limpieza de datos, EDA, pruebas Chi-cuadrado, Árboles de Decisión y PCA en Python para demostrar que la inflación responde a factores macroeconómicos, no políticos.
